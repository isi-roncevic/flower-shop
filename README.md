# flower-shop
This repositorium stores a project titled "Flower shop". 
The project simulates communication between a flower shop and a customer or a supplier of a shop. The purpose of communication is to create order or dilevery to the shop.  
Coding language used for the project is Java. A model used for communication is server/client, server being the flower shop, and client being customer or supplier. Communication is created using sockets and TCP.
